# maze-docs

Documentation for the Maze task with automatically generated distractors (A-maze), published at **https://vboyce.github.io/maze-docs**.

The site is the `docs/` folder, built by GitHub Pages (Jekyll, `jekyll-theme-minimal`). It covers:

- the current tools: [jspsych-maze](https://github.com/vboyce/jspsych-maze) (jsPsych plugin), [maze-distractor-generator](https://github.com/vboyce/maze-distractor-generator), and the [demos](https://vboyce.github.io/maze-demos)
- background on the method
- the older tools ([Maze](https://github.com/vboyce/Maze)'s `maze_automate` and [Ibex-with-Maze](https://github.com/vboyce/Ibex-with-Maze)), kept for existing projects

These pages used to live at vboyce.github.io/Maze, and the old URLs redirect here.

To preview locally, run `bundle exec jekyll serve` in `docs/` (needs Ruby and the `github-pages` gem).
