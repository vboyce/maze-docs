# Papers using A-maze

These are papers we know of that build on A-maze ([Boyce, Futrell, & Levy, 2020](https://www.sciencedirect.com/science/article/pii/S0749596X19301147); [Boyce & Levy, 2023](https://escholarship.org/uc/item/6vh9d8zm)). The list was assembled via reverse citaiton search and paper-skimming in September 2026. It is probably incomplete and may contain errors. Email me with corrections or additions. 

## Publications reporting experiments using A-maze, redo mode, and/or web-maze (ibex)

Papers that ran their own Maze experiments with A-maze distractors and/or the Ibex Maze controller, or that build a related method on A-maze.
